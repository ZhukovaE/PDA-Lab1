# Лабораторная работа № 3
## Обеспечение качества данных

**Дисциплина:** Параллельные и распределённые алгоритмы

### Цель работы
Исследование качества данных, выявление пропусков, дубликатов и ошибок, а также обработка и стандартизация данных с использованием Python.

### Выполненные задания

1. **Исследование данных:** анализ структуры датасета, пропущенных значений, уникальности и дубликатов.
2. **Обработка `location`:** определение форматов местоположений, выделение города, штата и почтового индекса.
3. **Обработка `salary`:** анализ форматов заработной платы, извлечение числовых значений и периодов оплаты.
4. **Обработка `job_type`:** нормализация видов занятости и выделение отдельных признаков.

### Результаты

В ходе работы был исследован датасет, содержащий 22 000 записей о вакансиях. Были обнаружены пропущенные значения, дубликаты и ошибки размещения информации. Проведена обработка основных текстовых столбцов для повышения качества данных.
