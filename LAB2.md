# Лабораторная работа № 2
## Работа с PySpark

### Описание

В лабораторной работе выполнен анализ данных
об авиаперевозках с использованием Apache Spark и PySpark.

### Выполненные задания

1. Анализ авиаперевозчиков.
2. Анализ популярных направлений авиаперелётов.
3. Исследование отмен и причин задержек рейсов.
4. Сравнение Python UDF, Pandas UDF и встроенных функций PySpark.
5. Прогнозирование отмен рейсов с помощью логистической регрессии.
